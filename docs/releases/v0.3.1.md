Sweep's first packaged release for macOS.

- Compact file tree with folder sizes, sorting, filtering, and keyboard/mouse navigation.
- Confirmation popup for permanent deletion.
- Background deletions with immediate tree updates; quit waits for pending operations.
- Cached navigation and incremental updates without full rescans.
- Optional administrator access through `sweep --sudo`.

### Install with Homebrew

```sh
brew tap jacobslunga/sweep https://github.com/jacobslunga/sweep
brew install jacobslunga/sweep/sweep
sweep
```

### Download a binary

Choose `darwin_arm64` for Apple Silicon or `darwin_amd64` for Intel. Both archives include the executable and README. Checksums are in `checksums.txt`.

Apple Silicon binaries have been tested locally. The Intel binary is cross-compiled and has not been run on an Intel Mac. These binaries are not Apple Developer ID signed or notarized.

Deletion is permanent and requires confirmation. The root scan directory itself cannot be deleted.
